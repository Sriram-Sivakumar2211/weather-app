# 🌦 Weather Application

A simple weather web application built using Node.js that fetches real-time weather data from OpenWeatherMap API.

---

## 🚀 Features

- Search weather by city name
- Displays:
  - City Name
  - Temperature (°C)
  - Weather Description
- Clean modern UI with CSS
- Uses OpenWeatherMap API
- Built with pure Node.js (no Express)

---

## 🛠 Technologies Used

- Node.js
- Axios
- HTML
- CSS
- OpenWeatherMap API
